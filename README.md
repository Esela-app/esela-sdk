> público donde vivirá el kit de integración de Esela. La API puede cambiar.

## Qué será

Esela es una plataforma para crear **historias sociales** visuales que ayudan a
niños con autismo a anticipar y comprender su día a día. Este SDK permitirá a
terceros:

- **Insertar el editor de historias** de Esela en sus propias webs/apps (embed)
- **Crear plugins** que extiendan el editor (nuevas herramientas, bloques, exportadores)
- **Integrar la búsqueda de pictogramas** (ARASAAC y biblioteca comunitaria)
- **Conectar con AsTeRICS Grid** y otras herramientas AAC

## Por qué Apache-2.0

El SDK es **abierto y permisivo** a propósito: queremos que cualquier desarrollador,
asociación o terapeuta pueda construir sobre Esela sin fricciones, incluso en
proyectos comerciales. Apache-2.0 permite uso libre y añade protección de patentes.

> El núcleo de la plataforma Esela es software propietario; **solo este SDK de
> integración es de código abierto.**
